# Finora 💜

Минималистичное мобильное приложение для учёта личных финансов на **Kotlin + Jetpack Compose**.

Считайте доходы и расходы, ведите счета (банки/кошельки), ставьте финансовые цели
и смотрите наглядную статистику — всё в чистом, аккуратном дизайне (Material 3, светлая и тёмная темы).

## Возможности

- 💳 **Счета (банки)** — добавляйте карты, наличные, накопительные счета и вклады; баланс по каждому считается автоматически.
- ➕ **Доходы и расходы** — быстрый ввод операции: сумма, категория, счёт, дата, комментарий.
- 🏷️ **Категории с иконками** — 17 готовых категорий с цветными иконками (продукты, кафе, транспорт, зарплата и т.д.).
- 🎯 **Цели** — копите на отпуск, технику или подушку безопасности; прогресс и пополнения.
- 📊 **Статистика** — круговая диаграмма по категориям, динамика доход/расход за 6 месяцев, разбивка по месяцам.
- 🌗 **Светлая и тёмная темы**, поддержка edge-to-edge.

## Стек

| Слой | Технологии |
|------|-----------|
| UI | Jetpack Compose, Material 3, Navigation Compose |
| Архитектура | MVVM + однонаправленный поток данных (StateFlow) |
| Данные | Room (SQLite), Kotlin Coroutines + Flow |
| DI | Лёгкий ручной контейнер (`AppContainer`) |
| Графики | Собственные чарты на Compose Canvas (без сторонних библиотек) |
| Сборка | Gradle (Kotlin DSL) + Version Catalog, KSP |

- Kotlin 2.0.20 · AGP 8.5.2 · Gradle 8.9
- compileSdk / targetSdk 34 · minSdk 24

## Как собрать

1. Открыть проект в **Android Studio** (Koala / Ladybug или новее).
2. Дождаться Gradle Sync (зависимости подтянутся автоматически).
3. Запустить конфигурацию `app` на эмуляторе или устройстве.

Или из терминала:

```bash
./gradlew assembleDebug
```

## Структура

```
app/src/main/java/com/finora/
├── data/            # Room: entity, dao, AppDatabase, мапперы, дефолтные данные
│   └── repository/  # FinanceRepository — единый источник данных
├── domain/model/    # Доменные модели и enum'ы
├── di/              # AppContainer (ручной DI)
└── presentation/
    ├── theme/       # Цвета, типографика, формы, тема
    ├── navigation/  # Граф навигации + нижняя панель
    ├── components/   # Переиспользуемые UI-компоненты и графики
    ├── util/        # Форматирование денег/дат, иконки, палитра
    ├── home/        # Главный экран
    ├── transactions/# Список операций
    ├── addtransaction/ # Добавление/редактирование операции
    ├── statistics/  # Статистика и графики
    ├── goals/       # Цели
    └── accounts/    # Счета
```

## Экраны

- **Главная** — общий баланс, доход/расход за месяц, карточки счетов, последние операции, цели.
- **Операции** — все транзакции, сгруппированные по дням, с фильтром доход/расход.
- **Статистика** — переключатель месяца, бар-чарт динамики, круговая диаграмма по категориям.
- **Цели** — карточки целей с прогрессом и пополнением.
- **Счета** — список счетов с балансами, добавление/редактирование.
